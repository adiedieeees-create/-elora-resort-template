# ÉLORA RESORT — Premium Website Template

A seven-page, responsive hotel and resort website template built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home
- `rooms.html` — Stay / room collection
- `experiences.html` — Resort experiences
- `dining.html` — Restaurant
- `gallery.html` — Image gallery with lightbox
- `about.html` — Brand story
- `contact.html` — Enquiry form demo

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser. For best results, run a local static server (for example, VS Code Live Server or `python -m http.server`).
3. Internet access is required for the remote Unsplash images and Google Fonts used in this demo.

## Before selling or publishing
- Replace every demo image with photographs that you own or have a suitable commercial licence to use. The current photographs are loaded from Unsplash image URLs for preview purposes; they are not bundled with this package.
- Replace demo contact details in `contact.html`.
- Connect the contact form to a real form handler or backend. The current form is front-end demonstration only and does not send messages.
- Update the brand, copy, SEO metadata, social links, and location details for the buyer's business.
- Test all pages and image assets after replacing content.

## Customisation
- Colours and typography variables are at the top of `assets/style.css`.
- Layout and responsive rules are in `assets/style.css`.
- Mobile menu, gallery lightbox, and demo form interaction are in `assets/script.js`.
- All pages use the same shared navigation and footer markup.

## Technical notes
- No framework, build step, database, or package installation is required.
- Responsive navigation is keyboard accessible and includes `aria-expanded` state.
- The enquiry form is intentionally a demo and must be connected before production use.
- External Google Fonts and image URLs can be replaced with locally hosted assets for a fully self-contained deployment.
